                                            Azure Resource Group Terraform Setup

Overview
Terraform module provisions a single Azure Resource Group. 
Resource groups are used to organize and manage related Azure resources. Provides a logical container for deployments, policies and access control.

Features
-Creates a Resource Group in a specified Azure region
-Outputs key information about the resource group for use in other modules or scripts
